Встановлення залежностей

Для графічних завдань потрібні:

pip install matplotlib networkx numpy

Завдання 1. Однозв'язний список

Реалізовано:

реверсування списку зі зміною посилань між вузлами;

сортування вставками;

об'єднання двох відсортованих списків в один.

Запуск:

python task_1.py

Складність:

реверсування — O(n);

сортування вставками — O(n²);

злиття двох відсортованих списків — O(n + m).

Завдання 2. Фрактал «дерево Піфагора»

Фрактал будується рекурсивно. Користувач може задати рівень рекурсії.

python task_2.py 8

Для запуску без відкривання графічного вікна:

python task_2.py 8 --no-show

Кількість гілок зростає експоненціально, тому для демонстрації доцільно використовувати рівні приблизно від 6 до 10.

Завдання 3. Алгоритм Дейкстри

Програма створює зважений неорієнтований граф і знаходить найкоротші шляхи від вершини A.

Для вибору вершини з найменшою поточною відстанню використовується heapq.

python task_3.py

Часова складність для списків суміжності та бінарної купи:

O((V + E) log V)

Завдання 4. Візуалізація бінарної купи

Список перетворюється на мінімальну купу за допомогою heapq.heapify, після чого купа відображається як бінарне дерево.

python task_4.py --no-show

Результат зберігається у файлі binary_heap.png.

Завдання 5. Обходи DFS та BFS

Реалізовано ітеративні алгоритми без рекурсії:

DFS — за допомогою стека;

BFS — за допомогою черги deque.

Колір вузла залежить від порядку відвідування: перші вузли темніші, наступні поступово світлішають.

python task_5.py

Результати:

DFS: [0, 4, 5, 10, 1, 3, 2]
BFS: [0, 4, 1, 5, 10, 3, 2]

Створюються dfs_traversal.png і bfs_traversal.png.

Завдання 6. Вибір їжі

Бюджет за замовчуванням — 100.

Жадібний алгоритм сортує страви за співвідношенням калорійності до вартості.

Динамічне програмування розв'язує задачу 0/1 knapsack та гарантує максимальну калорійність у межах бюджету.

python task_6.py

Для заданих даних:

Жадібний алгоритм:
страви = ['cola', 'potato', 'pepsi', 'hot-dog']
вартість = 80
калорійність = 870

Динамічне програмування:
страви = ['pizza', 'pepsi', 'cola', 'potato']
вартість = 100
калорійність = 970

Висновок: динамічне програмування дає кращий результат за калорійністю, хоча потребує більше обчислень і пам'яті.
